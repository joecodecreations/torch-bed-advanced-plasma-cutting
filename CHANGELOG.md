# Changelog

## Unreleased

First public version.

- Jog control, bed setup with corner teaching, click-to-move.
- Drawing tools, pen tool with curves, image trace, SVG and DXF import, shape combining, unit maths.
- Cut order list, materials with cut width, dry runs, cutting with an arm switch.
- 2D and 3D cut preview with timeline.
- 3D model slicing: stacked layers and interlocking grids, never-undersize outlines, plan ranking, multi-sheet nesting, assembly guide, model overlay.
- Finish to shape: per-side depth maps of the material to remove, laser calibration per material, image export.
- 3D formats: STL, OBJ, GLB/glTF, 3MF, PLY, OFF, AMF, 3D DXF; .blend, FBX, USD and more through Blender.
- Board tab: wiring diagram, GRBL settings editor, built-in firmware flashing with automatic backup.
- Projects with autosave and crash recovery.
- Windows, macOS and Linux serial support with no dependencies.

Not yet validated on real hardware.
